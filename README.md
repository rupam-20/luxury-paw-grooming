# Luxury Pet Grooming

A modern and responsive Luxury Pet Grooming Salon website built using HTML, CSS, and JavaScript.

## Features

* Responsive Design (Mobile, Tablet, Desktop)
* Modern Hero Section
* Services Showcase
* Pricing Section
* Customer Testimonials
* Contact Section
* Smooth Scrolling Navigation
* Interactive UI Elements
* Optimized Performance

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/rupam-20/luxury-pet-grooming-.git
```

2. Open the project folder.

3. Run `Index.html` in your browser.
